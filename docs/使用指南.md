# 离墨电脑配置单管理助手使用指南

## 1. 下载与启动

普通用户请从 [GitHub Releases](https://github.com/limonet003/limo-pc-build-sheet-manager/releases) 下载完整发布包，解压后保持文件夹结构不变，双击 `离墨电脑配置单管理助手.exe`。

运行要求：

- Windows 10 或 Windows 11
- Microsoft Excel
- Excel 允许打开包含 VBA 宏的 `.xlsm` 文件

软件默认查找 `报价单/离墨DIY电脑装机配置报价单.xlsm`。如果移动过报价单，可在右上角“设置”中重新选择。

## 2. 软件主界面

![软件主界面](images/app-overview.png)

主界面分为四个主要区域：

- **型号主库**：导入、搜索、启用、停用和删除配件型号。
- **供应商报价**：记录实际进货成本、库存和供应商信息。
- **渠道绑定**：绑定平台 SKU、店铺、标题或商品链接。
- **手动价格单**：导入渠道价格，不连接或采集电商平台。

右侧“本次报价清单”用于选择需要同步到 Excel 的型号。“同步报价”写入报价单，“同步打开”写入后直接打开报价单。

## 3. 导入模板

仓库和发布包内提供四份 CSV 模板：

| 模板 | 用途 |
| --- | --- |
| `型号主库导入模板.csv` | 新增或更新配件型号、包装类型、兼容参数和手动价格 |
| `供应商报价导入模板.csv` | 导入供应商、进货价、库存和报价时间 |
| `渠道SKU绑定模板.csv` | 绑定平台商品 ID、店铺、标题和链接 |
| `价格单导入模板.csv` | 导入手动渠道价格 |

建议使用 UTF-8 CSV。型号主库中的“型号”应尽量唯一；CPU 可在“包装类型”中区分“盒装”和“散片/Tray”。

## 4. 同步到报价单

1. 在型号主库中勾选或搜索需要报价的型号。
2. 点击“加入报价”。
3. 在右侧清单确认型号。
4. 点击“同步报价”或“同步打开”。

同步没有条数上限，但 Excel 单个工作表最多支持 1,048,576 行。大量型号会增加文件体积和下拉检索时间。

## 5. 自定义型号与手填价格

![支持自定义型号的报价单](images/quote-sheet.png)

“品牌及型号”单元格既可以使用下拉列表，也可以直接输入未收录的商品型号。自定义型号会显示蓝色“自定义”状态。

自定义型号没有数据库价格时，直接在“单价”列输入销售价即可。输入后单价仍由报价单内部公式管理，因此换型号、一键清空和历史恢复不会遗留上一件商品的价格。

含自定义 CPU、主板、内存、显卡或电源时，智能检查会显示“含自定义型号，无法自动检查”。这代表缺少兼容参数，并不代表不兼容，需要人工核对。

## 6. 价格与利润

当前报价的销售价优先级如下：

1. 报价单中直接手填的单价或历史报价快照。
2. 型号主库中的手动销售价。
3. 根据进货成本和“设置与规则”中的目标毛利率计算销售价。

利润列默认隐藏，可在“设置与规则”中点击“显示利润”。目标毛利率由用户自行填写。

## 7. 保存、恢复与清空

- **保存报价**：把当前报价写入“历史报价”。
- **恢复**：恢复客户信息、型号、数量、成交单价和成本快照。
- **删除**：删除指定历史记录；删除后可立即按 `Ctrl+Z` 撤销。
- **新建报价 / 一键清空**：清除客户姓名、联系方式、预算、型号、手填单价和价格快照，数量恢复为 1。
- **撤销清空**：清空后立即按 `Ctrl+Z`，可恢复刚才的报价。

历史报价自动保留 7 天。点击“一键清空”不会自动保存，重要报价请先点击“保存报价”。

## 8. 宏无法运行

如果按钮点击后没有反应：

1. 确认文件扩展名为 `.xlsm`。
2. 关闭 Excel 后重新打开报价单。
3. 在 Excel 顶部安全提示中选择“启用内容”。
4. 如果文件来自网络下载，右键文件，打开“属性”，勾选“解除锁定”后重新打开。
5. 不要把报价单另存为 `.xlsx`，否则 VBA 宏会被删除。

## 9. 数据与隐私

软件在本机运行，不自动访问京东或其他电商平台，也不绕过登录、验证码或反爬限制。GitHub 仓库不包含用户数据库、客户报价历史、本机配置、日志或备份文件。
